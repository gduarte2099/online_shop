# Tienda de electrónica (React + Vite + Tailwind)
1. Copiá tu carpeta `img/` original dentro de `public/img/` (mismas subcarpetas: teclados, tablets, TVs...). Si una imagen falta, se muestra un placeholder.
2. `npm install` y `npm run dev`
3. Productos: `src/data/products.json` · Número de WhatsApp y menú: `src/data/config.js`
